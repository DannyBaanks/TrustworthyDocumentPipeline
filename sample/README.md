# Sample Documents

Fixtures used by the offline demo, the real Nutrient integration test, and the
judging flow. They contain no personal data.

## `invoice.pdf`

A deterministic, fictional invoice generated by
[`tools/generate_invoice.py`](../tools/generate_invoice.py):

- `vendor_name`: Acme Supply Co.
- `invoice_number`: INV-2026-0012
- `issue_date`: 2026-07-14
- `currency`: USD
- `total_amount`: 106.55
- `line_items`: 3 rows whose arithmetic reconciles (90.30 + 18% = 106.55)

Regenerate with:

```powershell
python tools/generate_invoice.py sample/invoice.pdf
```

## `research-paper.pdf`

An open-access scientific article used to demonstrate the honest "wrong
document type" path: a real Nutrient run on a non-invoice produces few or no
invoice fields, validation fails, and the decision is routed to human review.

> Luncz LV, Tan A, Haslam M, Kulik L, Proffitt T, Malaivijitnond S, Gumert M
> (2017) Resource depletion through primate stone technology. eLife
> 6:e23647. DOI: 10.7554/eLife.23647. Licensed CC BY 4.0.

Each real Nutrient call consumes API credits; the free tier includes 5,000
credits per month.
